  • Autoplay config

    1. about:config
    2. media.autoplay.default = 5 [0:allow;1:blockAudible;2:Prompt;5:blockAll]
    3. media.autoplay.blocking_policy = 2
    4. media.autoplay.allow-extension-background-pages = false
    5. media.autoplay.block-event.enabled = true

  • Change default zoom levels ↺

    1. about:config
    2. toolkit.zoomManager.zoomValues
    3. modify with: .3,.5,.67,.8,.9,.92,.95,1,1.1,1.2,1.33,1.5,1.7,2,2.4,3,4,5 (adds 92% and 95%)

  • Re-enable popup notification ↺

    1. about:config
    2. privacy.popups.showBrowserMessage (set to true)
    3. browser.tabs.warnOnOpen (set to true)
    4. browser.tabs.maxOpenBeforeWarn (optional)

  • Change allowed pop-up events ↺

    1. about:config
    2. dom.popup_allowed_events (leave this parameter blank to disable all types of pop-up allowable events)

    Note: original= change click dblclick auxclick mousedown mouseup pointerdown pointerup notificationclick reset submit touchend contextmenu

  • Change toolbar size to compact mode ↺

    1. about:config
    2. browser.compactmode.show (set to true)

  • Disable prompt "Prevent this page from creating additional dialogs" ↺

    1. about:config
    2. Create a new "dom.successive_dialog_time_limit" parameter in Number format.
    3. Set to 0 (seconds) or 2 (recommended), which will set the number of seconds between successive prompts for safety reasons.

  • How to take screenshots using console↺

    1. Enable console with Ctrl-Shift-K (Windows) or Cmd-K (Mac)
    2. Enter the following sample command:
      :screenshot --dpr 3 --fullpage --filename C:\Temp\Test.png

    Click here for info on additional parameters.

  • Create default user stylesheet that applies to all websites† ↺

    1. Locate profile folder in Windows Explorer:
      • about:support
      • Profile Folder -> Open Folder
    2. Create a "chrome" directory within the designated profile folder.
    3. Add a "userContent.css" file in this directory.
    4. Specify CSS styles in userContent.css, which will be applied to all websites.
      Example: body { font-family: 'Poppins' !important; font-size: 16px !important; line-height: 20px !important; margin-bottom: 14px !important; }
    † May not be supported in all versions.

  • Extensions info and local storage ↺

    • about:debugging#/runtime/this-firefox
    • C:\Users\[user]\AppData\Roaming\Mozilla\Firefox\Profiles\[profile-name]\extensions\

  • Useful extensions ↺

    1. New Tab Override - specifies a webpage to open when a new tab is created
    2. WhatFont - identifies font family used in webpages
    3. Magic CSS - allows for coding custom CSS overrides in webpages

  • Disable plug-in signing requirement ↺

    1. about:config
    2. Set xpinstall.signatures.required to false.
    3. Set extensions.langpacks.signatures.required to false.

  • Temporarily allow unsigned add-ons ↺

    1. about:debugging
    2. Click on "This Firefox".
    3. Click on "Load Temporary Add-on..." button.
    4. Select an XPI file.

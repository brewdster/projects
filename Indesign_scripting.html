  • Move & ungroup objects to new layers ↺
    var doc = app.activeDocument; var myLayer = doc.layers.item(prompt("Enter name of Layer","Source")); for (i = 0; i < myLayer.pageItems.length; i++) { var lyr = myLayer.pageItems[i].name; myLayer.pageItems[i].itemLayer = doc.layers.add({name:myLayer.pageItems[i].name, layerColor: UIColors.LIGHT_OLIVE}); doc.layers.item(lyr).groups.item(lyr).ungroup(); i = i - 1; } myLayer.remove(); doc.layers.everyItem().ignoreWrap = true; alert("Process complete!"); Note: Sample code moves all grouped objects under a specified layer into their own layers with the same names as the grouped objects. Also ungroups them and turns off wrapping when layers are hidden. Important: For the ungroup step to function properly, the "Ungroup Remembers Layers" option must be TURNED OFF in the Layers panel menu.

  • Turn off all ligatures and hyphenation ↺
    var doc = app.activeDocument; var stories = doc.stories.everyItem().getElements(); var pargs = doc.paragraphStyles; for (i = 0; i < stories.length; i++) { stories[i].paragraphs.everyItem().ligatures = false; stories[i].paragraphs.everyItem().hyphenation = false; } for (j = 1; j < pargs.length; j++) { pargs[j].ligatures = false; pargs[j].hyphenation = false; } alert("Process complete!");

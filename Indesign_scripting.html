  • Move & ungroup objects to new layers ↺
    var doc = app.activeDocument; var myLayer = doc.layers.item(prompt("Enter name of Layer","Source")); for (i = 0; i < myLayer.pageItems.length; i++) { var lyr = myLayer.pageItems[i].name; myLayer.pageItems[i].itemLayer = doc.layers.add({name:myLayer.pageItems[i].name, layerColor: UIColors.LIGHT_OLIVE}); doc.layers.item(lyr).groups.item(lyr).ungroup(); i = i - 1; } myLayer.remove(); doc.layers.everyItem().ignoreWrap = true; alert("Process complete!"); Note: Sample code moves all grouped objects under a specified layer into their own layers with the same names as the grouped objects. Also ungroups them and turns off wrapping when layers are hidden. Important: For the ungroup step to function properly, the "Ungroup Remembers Layers" option must be TURNED OFF in the Layers panel menu.

  • Turn off all ligatures and hyphenation ↺
    var doc = app.activeDocument; var stories = doc.stories.everyItem().getElements(); var pargs = doc.paragraphStyles; for (i = 0; i < stories.length; i++) { stories[i].paragraphs.everyItem().ligatures = false; stories[i].paragraphs.everyItem().hyphenation = false; } for (j = 1; j < pargs.length; j++) { pargs[j].ligatures = false; pargs[j].hyphenation = false; } alert("Process complete!");

  • Create a simple rectangle object ↺
    var myDoc = app.activeDocument; var rect =myDoc.rectangles.add({geometricBounds : [3,5,5,3] ,fillColor : myDoc.colors.itemByName("Black")});

    Note: [3,5,5,3] represents the x/y vectors of a 2x2-inch square at vector x=3 and y=3, with the 4 corners starting from the upper-left corner in a clockwise direction, where 3 = y position, 5 = x pos., 5 = y pos., 3 = x pos.

  • GREP: Target phrase before and after specific word(s) ↺
    GREP code: (?i)(?<=the ).+?(?= dog)
    Result: The cute dog ate its dogfood quickly.

    • (?i) makes search term case-insensitive.
    • (?<=the ), also called a Positive Lookbehind, specifies the phrase "the " (note the space after "the") as the required before criteria, meaning the string searched for must be preceded by "the ".
    • .+ applies GREP style to any and all characters in-between the 2 criteria specified in the example, so long as both criteria exist.
    • ?(?= dog), also called a Positive Lookahead, specifies the phrase " dog" (note the space before "dog") as the required after criteria, meaning the string searched for must be followed by " dog".
      Note: The preceeding "?" before the opening parenthesis denotes only the first match is considered (non-greedy); otherwise, the criteria will be applied to the second "dog" in "dogfood".
      This criteria can also be expressed as (?= \bdog\b), where "\b" or "word boundary" indicates a full-word search. This will apply the criteria to " dog " but not to "dogfood".

    Another option is ^(?i)[^d]+\K(cute) where:

    • ^(?i)[^d] establishes the search range from the start of the paragraph "^" to the first "d" character, case-insensitive.
    • +\K(cute) is an inclusive LookBehind search for the word "cute" in the established range from the previous step.

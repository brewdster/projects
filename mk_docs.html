  • Creating sequence nos. ↺

    1. SubString(AsString(GetEnv("CurRecordNumber") + 100000), 1) ex: 00123
    2. AsString(GetEnv("CurRecordNumber") + 10000) ex: 10123
    3. "2" & FormatNumber(GetEnv("CurRecordNumber"), "0000") ex: 20123
    4. SubString("##########", 0, 6 - Length(GetEnv("CurRecordNumber"))) & GetEnv("CurRecordNumber") ex: ###123
    5. GetEnv("CurRecordNumber") & SubString("**********", 0, 6 - Length(GetEnv("CurRecordNumber"))) ex: 123***

  • Check record sequence
    If(GetEnv("CurRecordNumber") <> Asnumber(Substring(Trim(|->[SEQNO]), 1))) { abort } else { GetEnv("CurRecordNumber") }

  • Adobe tagged-text scripts for Text ADOR with programmable styles ↺

    1. Font script (ex: @{fs})
      "<UNICODE-WIN>\r\n<Version:17.2><FeatureSet:InDesign-Roman><ParaStyle:NormalParagraphStyle><pHyphenation:0><pSpaceAfter:4.500000><ColorTable:=<Black:COLOR:CMYK:Process:0,0,0,1>>"
    2. Font styles (ex: @{Geor_R12} or @{Pop_B14})
      "<cTypeface:Regular><cSize:12.000000><cLeading:14.000000><cUnderline:0><cPosition:><cFont:Georgia>" // Georgia Regular 12 pt. with 14 pt. leading
      or
      "<cTypeface:Bold><cSize:14.000000><cLeading:16.000000><cUnderline:1><cPosition:><cFont:Poppins>" // Poppins Bold Underlined 14 pt. with 16 pt. leading
      * Include the quotes in code.
    3. Notes:
      • Start the Qlingo statement in your Text ADOR with the following example:
        @{fs} & @{Geor_R12} & "My paragraph text..."
      • The font typeface (Bold, Regular, etc.), size, underline (0 or 1), and name (Georgia, Poppins, etc.) can be substituted with variables:
        ex: "<cTypeface:" & |->[style1] & "><cSize:" & |->[size] & "><cUnderline:0><cPosition:><cColor:" & @{var_col1} & "><cFont:" & |->[font_name] & ">"
      • Specify gaps between paragraph breaks with <pSpaceAfter:4.500000> in font scripts or styles, where point size equals inches multiplied by 72 (e.g. 0.0625 * 72 = 4.5).
      • Specify line spacing (leading) with <cLeading:15.000000> in font scripts or styles. "Auto" is used when this parameter is ommitted.
      • For additional style properties (i.e. <cPosition:Superscript>, <cColor:C=0 M=0 Y=0 K=100>, etc.), highlight sample text and export to “Adobe tagged text” or refer to the following manual.
    4. Examples:
      • If control @{fs} & If(Ucase(Trim(|->[LANG])) = "E") { @{Geor_R12} & @{var_sal1} & " you for your " & @{Geor_B12} & "continued support" & @{Geor_R12} & @{var_years} & "." } Else If(Ucase(Trim(|->[LANG])) = "F") { @{Geor_R12} & "Merci pour votre " & @{Geor_B12} & "soutien continu" & @{var_sal3} & "." } Else { ReportMessage("Invalid PARACALL [" & Trim(UCase(|->[PARACALL])) & "] in record " & GetEnv("CurRecordNumber") & ".")abort }
      • Switch control @{fs} & Switch(Trim(UCase(|->[PARACALL]))) { Case "A": @{Geor_R12} & @{var_sal1} & " you for your " & @{Geor_B12} & "continued support" & @{Geor_R12} & @{var_years} & "." Case "B": @{Geor_R12} & "We couldn\'t have done it without you" & @{var_sal2} & @{Geor_R12} & "." default: ReportMessage("Invalid PARACALL [" & Trim(UCase(|->[PARACALL])) & "] in record " & GetEnv("CurRecordNumber") & ".")abort }

  • QLingo string functions ↺

    • Lcase("HELLO") = "hello"
    • Tcase("hello world") = "Hello World"
    • UCase("hello") = "HELLO"
    • Length("abc") = 3
    • IsNullOrEmpty(|->[field]) = true or false
    • SubString("hello",1,2) = "el"
    • Trim(" Hello World ") = "Hello World"
    • LTrim(" Hello World ") = "Hello World "
    • RTrim(" Hello World ") = " Hello World"
    • Find("Hello World", "o", 5) = 7 // returns -1 if value not found
    • Replace("Hello World", "old w", 6, 1) = "Hello old world"
    • FindAndReplace("Hello World", "World", "Earth") = "Hello Earth"
    • FindAndReplace(TCase(FindAndReplace("MARIE-JOSEE","-","- ")),"- ","-") = "Marie-Josee"
    • FindAndReplaceChars("A1B2C3D4E5", "12345", "*") = "A*B*C*D*E*"
    • CleanNumber("A1B2!3@4?5") = "12345"
    • "Hello" + HexToUnicode("0020") + "World" = "Hello World" // 0020 = 'space'; 0009 = 'tab'

  • QLingo numeric functions ↺

    • ABS(-5) = 5
    • Floor(3.78) = 3
    • Ceil(3.78) = 4
    • Ceil(82/5)*5 = 85 (rounding up to nearest 5)
    • FormatNumber(5000.2,"$#,###.00") = $5,000.20
    • Rand(1) can equal 0.9528 (value will be < 1)
    • Round(12.344, 2) = 12.34
    • 1 + (|->[Index] - 1) % 4 // Modulus 4
    • 5 div 2 = 2 // Normal division but drops the decimals and returns whole number

  • QLingo date functions ↺

    • GetDay("14/09/2023") = 14
    • GetMonth("14/09/2023") = 9
    • GetYear("14/09/2023") = 2023
    • GetDayOfWeek("14/09/2023") = 5
    • GetHour("14/09/2023 12:57:20") = 12
    • GetSecond("14/09/2023 12:57:20") = 20
    • Age("21/12/1970") = 52.7315068493151 (as of Sep. 14, 2023)
    • Now() = 9/14/2023 8:00:36 PM
    • FormatDate(#14/09/2023#, "dddd, MMMM dd, yyyy") = "Thursday, September 14, 2023"

      d Displays the day as a number without a leading zero (for example, 1).
      dd Displays the day as a number with a leading zero (for example, 01).
      ddd Displays the day as an abbreviation (for example, Sun).
      dddd Displays the day as a full name (for example, Sunday).
      M Displays the month as a number without a leading zero (for example, January is represented as 1).
      MM Displays the month as a number with a leading zero (for example, 01/12/01).
      MMM Displays the month as an abbreviation (for example, Jan).
      MMMM Displays the month as a full month name (for example, January).
      y Displays the year number (0-9) without leading zeros.
      yy Displays the year in two-digit numeric format with a leading zero, if applicable.
      yyy Displays the year in three-digit numeric format.
      yyyy Displays the year in four-digit numeric format.
      h Displays the hour as a number without leading zeros using the 12-hour clock (for example, 1:15:15 PM).
      hh Displays the hour as a number with leading zeros using the 12-hour clock (for example, 01:15:15 PM).
      H Displays the hour as a number without leading zeros using the 24-hour clock (for example, 1:15:15).
      HH Displays the hour as a number with leading zeros using the 24-hour clock (for example, 01:15:15).
      m Displays the minute as a number without leading zeros (for example, 12:1:15).
      mm Displays the minute as a number with leading zeros (for example, 12:01:15).
      s Displays the second as a number without leading zeros (for example, 12:15:5).
      ss Displays the second as a number with leading zeros (for example, 12:15:05).
      T Displays an uppercase 'A' for any hour before noon; displays an uppercase 'P' for any hour between noon and 11:59 P.M.
      TT Displays an uppercase 'AM' for any hour before noon; displays an uppercase 'PM' for any hour between noon and 11:59 P.M.
      t Displays an lowercase 'a' for any hour before noon; displays an lowercase 'p' for any hour between noon and 11:59 P.M.
      tt Displays an lowercase 'am' for any hour before noon; displays an lowercase 'pm' for any hour between noon and 11:59 P.M.
      Any other Display as is.

  • QLingo system functions ↺

    • GetEnv("CurRecordNumber") // Gets record number or current record.
    • abort // Used in If/Else or Switch statements. Prompts an error.
    • skip // Used in If/Else or Switch statements. Skips current record.
    • GetPDFAssetPageCount("file1.pdf") // Gets total pages in pdf.
    • "file1.pdf:3" // Pulls page 3 from file1.pdf into Graphic content object. Need to set "Assets" folder location.
    • IsAssetExist("Pic1", 3) // Checks if asset exist; 3 = image, 8 = pdf
    • IsFileExist("C:\\myfile.txt") // Checks if file path/URL exists (True/False)
    • ReportMessage("Custom message") // Shows custom message during production; must be followed by expression (e.g. Skip or Abort)
      ex: ReportMessage("Error in record " & GetEnv("CurRecordNumber") & ".")abort

  • UV2STR (user view to string) function
    Syntax: UV2STR([my_view],"line prefix","line suffix","separator",true or false*)
    * include header
    Example 1 creates a CSV table from Orders user view:
    UV2STR([Orders],"","\r\n",",",true)
    Result: customer id,order id,order date,product id,product name,qty,unit_price,total_price A10025,1001,2024-02-29,0085,Highliter-Yellow,2,$1.50,$3.00 A10025,1005,2024-04-12,0011,Sticky Notes-small,5,$1.00,$5.00
    Example 2 creates an HTML table from Orders user view: "<table>\r\n<tbody>\r\n" & UV2STR([Orders],"\t<tr>\r\n\t\t<td>","</td>\r\n\t</tr>\r\n","</td>\r\n\t\t<td>",false) & "</tbody>\r\n</table>"
    Result: <table> <tbody> <tr> <td>A10025</td> <td>1001</td> <td>2024-02-29</td> <td>0085</td> <td>Highliter-Yellow</td> <td>2</td> <td>$1.50</td> <td>$3.00</td> </tr> <tr> ... </tr> </tbody> </table>

    Note: Can also be used to create complex Adobe Tagged Text table ADORs.

  • Steps to re-create local SQLDB ↺

    1. Run CMD.
    2. Type "SQLLocalDB info" to confirm that MSSQLLocalDB is installed.
    3. SQLLocalDB stop MSSQLLocalDB
    4. SQLLocalDB delete MSSQLLocalDB
    5. Go to "C:\users\[name]" folder ("%UserProfile%") and delete all files with .ldf and .mdf extensions, if they exist.
    6. SQLLocalDB create MSSQLLocalDB
    7. SQLLocalDB start MSSQLLocalDB

  • Sample Indesign Javascript code ↺
    var doc = app.activeDocument; var myLayer = doc.layers.item(prompt("Enter name of Layer","Source")); var cnt = myLayer.pageItems.length-1; for (i = cnt; i > -1; i--) { var lyr = myLayer.pageItems[i].name; myLayer.pageItems[i].itemLayer = doc.layers.add({name:lyr, layerColor: UIColors.LIGHT_OLIVE}); doc.layers.itemByName(lyr).groups.itemByName(lyr).ungroup(); } myLayer.remove(); doc.layers.everyItem().ignoreWrap = true; alert("Process complete!");

    Note: Sample code moves all grouped objects under a specified layer into their own layers under the same names as the grouped objects.
    Also ungroups them and turns off wrapping when layers are hidden.
    Important: For the ungroup step to function properly, the "Ungroup Remembers Layers" option must be TURNED OFF in the Layers panel menu.
